# Outfit 浏览器图标设计规格

## 背景

Outfit 是一个本地优先的穿搭管理与推荐工具。它从淘宝订单页或商品详情页采集服饰候选，导入本机 SQLite 衣橱库，再结合天气、场合和最近穿着记录生成可解释的搭配建议。

当前产品不是时尚内容站，也不是云端导购平台，而是一个个人本地工作台。主界面采用深色侧栏、浅色工作区、8px 圆角控件和青绿色操作状态。图标需要延续这种克制、实用、可信的工作台气质，同时比现有通用 T 恤图标更明确地表达“今日推荐”和智能搭配。

## 已批准方向

采用“智能衣橱 T 恤”方向：

- 深 slate 圆角方底，呼应侧边栏与 PWA `theme_color`。
- 白色 T 恤作为主体，保证浏览器标签页 16px 尺寸下仍能优先识别为穿搭/衣物应用。
- 底部青绿色短线延续现有 `public/icon.svg` 的品牌记忆，并表达已确认、已选择、已整理的工作台状态。
- 右上角加入一个主星点和一个小星点，表达“今日推荐”“智能搭配”“可解释建议”，但不使用复杂魔杖、云、太阳、多件衣物或真实商品图。

该方向已由用户在 2026-06-21 批准。

## 视觉规格

### 画布

- SVG 画布使用 `viewBox="0 0 128 128"`。
- 背景为 128 x 128 圆角矩形。
- 圆角半径为 `24`，与现有图标和应用中 8px 圆角体系成比例。

### 颜色

只使用项目现有视觉语言中的颜色，不引入新品牌色：

| 用途 | 颜色 |
| --- | --- |
| 背景 | `#111827` |
| 衣物主体 | `#f8fafc` |
| 推荐/确认强调 | `#5eead4` |
| 次级星点 | `#99f6e4` |

### 图形构成

- T 恤主体居中偏下，占据主要识别面积。
- T 恤轮廓保持粗块面，而不是细线图标，避免小尺寸变糊。
- 青绿色短线位于衣物下半部，使用圆头描边。
- 星点位于右上角，不压住 T 恤主体。
- 星点数量限制为两个，避免标签页尺寸拥挤。

### 不采用的元素

- 不使用模特、人像、真实衣物图片或商品图。
- 不使用多件衣物组合，避免在 16px 下不可读。
- 不使用云、太阳、定位、数据库圆柱等额外业务符号，避免概念过载。
- 不使用渐变、阴影、滤镜或外部字体，保持 SVG 简洁稳定。

## 接入范围

### 文件改动

实现阶段只需要以下最小改动：

1. 更新 `public/icon.svg` 为最终 SVG。
2. 在 `index.html` 的 `<head>` 中新增显式 favicon 链接：

```html
<link rel="icon" type="image/svg+xml" href="/icon.svg" />
```

`public/manifest.webmanifest` 已指向 `/icon.svg`，`public/service-worker.js` 已缓存 `/icon.svg`，因此本次不需要新增 PNG、ICO、Apple touch icon 或修改 service worker。

### 缓存和兼容

- SVG favicon 覆盖现代浏览器标签页和 PWA manifest 图标。
- 浏览器可能缓存旧 favicon；验证时需要硬刷新或重新打开页面。
- 不新增 `/favicon.ico`，因为当前目标是“浏览器中那个”图标，且项目已有 SVG PWA 图标路径。旧浏览器 ICO 兼容不纳入本次范围。

## 验证标准

实现完成后，需要验证以下事项：

1. `public/icon.svg` 是合法 SVG，且包含 128 x 128 画布、深色背景、T 恤主体、青绿色短线和星点。
2. `index.html` 明确包含 `rel="icon"` 链接，指向 `/icon.svg`。
3. `npm run build` 通过。
4. 构建后的 `dist/index.html` 保留 favicon 链接。
5. 启动本地 Web 后，访问 `/icon.svg` 返回 200。
6. 浏览器标签页显示新图标，16px 下主体仍可识别为衣物图标。

## 设计自检

- 没有未定事项或占位内容。
- 设计范围聚焦浏览器 favicon，不扩展到完整品牌系统。
- 图形语义与项目核心一致：本地衣橱、可解释推荐、工作台式管理。
- 实现路径与现有 Vite public 资源、manifest、service worker 保持一致。
