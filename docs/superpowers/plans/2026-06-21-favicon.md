# Favicon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Outfit's browser favicon with the approved "智能衣橱 T 恤" SVG and explicitly connect it in the HTML head.

**Architecture:** Keep the implementation inside Vite's existing static asset path. `public/icon.svg` remains the single source for both PWA manifest and browser favicon, while `index.html` adds an explicit `rel="icon"` link so browsers do not rely on implicit discovery.

**Tech Stack:** React + Vite + TypeScript app, static SVG in `public/`, HTML entrypoint in `index.html`, validation through PowerShell checks and `npm run build`.

### Task 2: Add explicit browser favicon link

**Files:**
- Modify: `index.html`

- [ ] **Step 1: Add the icon link in `<head>`**

The final head should contain both favicon and manifest links:

```html
<meta name="theme-color" content="#1f2937" />
<link rel="icon" type="image/svg+xml" href="/icon.svg" />
<link rel="manifest" href="/manifest.webmanifest" />
```

- [ ] **Step 2: Verify the link is present**

Run:

```powershell
Select-String -LiteralPath '.\index.html' -Pattern '<link rel="icon" type="image/svg\+xml" href="/icon.svg" />' -Encoding UTF8
```

Expected: one match in `index.html`.

### Task 4: Runtime favicon check

Expected: HTTP 200 with `Content-Type` containing SVG content.

Open `http://127.0.0.1:5174` and hard refresh if needed. Expected: browser tab shows the dark rounded icon with a white T-shirt and teal recommendation star.
